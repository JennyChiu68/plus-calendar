# 金十 PLUS 日历

八主题真实公开日程与交互 Demo。产品方案：`docs/PLUS日历完整产品方案.md`；接入说明：`docs/真实数据接入说明.md`；网页方案：`public/proposal.html`。

## 运行

- `npm install`、`npm run dev`
- `npm run sync:data` 抓取官方日程并生成本地数据快照
- `npm run test:data` 日期、来源、ICS、导入失败保护等 13 组检查
- `npx tsc --noEmit`
- `npm run build` 静态导出至 `dist/client`
- `python3 scripts/render-proposal.py` 同步方案网页与下载版

## 数据与范围

2026-09-09 已接入 73 项真实日程，来自 40 个官方信源入口。33 个页面自动适配，共 46 项；另有 7 个核对入口，共 27 项。每条含官方出处与采集时间。当前为发布时快照，未启用定时更新；修改数据后需重新构建发布。营收等指标数值尚未接入。

自动来源清单：`data/sources.json`；人工记录：`data/manual-events.json`；前端使用：`data/calendar.json`；本次抓取报告：`data/sync-report.json`。人工记录不会被脚本自动续签核对日期。任一自动来源抓取或解析失败时停止整批写入，保留之前数据。

AI 与算力、机器人与具身智能、半导体、智能汽车与电池、商业航天、创新药与医疗、能源与电力、政策与监管八主题，居中最大宽度 1240px。保留简洁标签，移除日期待定、彩色日期圆点、重点侧栏、评分、日更持仓、前瞻与研究说明。支持多日会议跨周/月显示与 ICS 导出。

订阅、自选和提醒只保存至当前浏览器 localStorage，不发送推送；会员切换仅为交互演示。没有生产账号、收费、行情与跨端同步。
