# 金十 PLUS 日历产品演示

产品方案：`docs/PLUS日历完整产品方案.md`；可阅读网页：`public/proposal.html`。

## 运行

- `npm install`
- `npm run dev`
- `npm run build`（静态导出到 dist/client）
- `node --test scripts/calendar.test.ts`
- `npx tsc --noEmit`
- 修改方案后执行 `python3 scripts/render-proposal.py` 同步网页与下载版。

## 范围与数据

本项目是概念 Demo。只有台积电月营收日程及其前值为已核验官方样本；其余事件与数值均为模拟，行内及详情有明确标识。模拟事件的外链只是候选信源，不证明其标题或日期真实。

订阅、自选和提醒保存在当前浏览器 localStorage。没有生产账号、真实会员收费、后台推送、爬虫、行情服务或跨端同步。免费/会员切换仅为交互演示，生产权限必须在服务端实现。月视图在窄屏可横向滚动。

## 当前界面

四个主题：AI 与算力、人形机器人、政策与监管、能源与电力。移除资金与持仓及日更 ETF 样本。当前聚焦主题与日程丰富度，不提供前瞻、核验要点、产业研究关联与复盘。主页面仅展示日程、重点、待确认窗口与变更，产品解释集中在独立方案页。采用深色文字和白底分区，保留精简样例标记。

## 验证

类型检查、生产静态构建，以及 6 组日期、窗口、ICS 格式/UTF-8折行和来源约束测试。按当前 Sites 工作流未执行浏览器交互或截图测试；正式接入金十前必须按方案第 13 节执行生产验收。

## 发布

静态文件发布，不部署运行时 Worker，不接收生产数据。官方脚手架安装审计提示构建依赖/服务端依赖 advisories；本 Demo 用静态导出避免部署 RSC/开发服务器及图像解析服务。转为服务端产品前须更新并重新审计相关依赖，不能把当前演示作为服务端安全基线。
